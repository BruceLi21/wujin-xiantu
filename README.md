# 無盡仙途 V17 — 手機遊戲 UI 重構版

這版不是在 V16 上繼續縮字或補 CSS，而是依照參考遊戲的資訊架構重新設計：

- 固定手機直式遊戲框架，所有主頁皆不使用整頁上下捲動。
- 頂部角色總覽固定：境界 / 修為 / 靈石 / 戰力。
- 四個主頁各自獨立：修煉 / 歷練 / 洞府 / 角色。
- 修煉頁：當前境界、突破、修煉方式集中在一屏。
- 歷練頁：戰鬥紀錄在上，副本每頁 2 個，左右翻頁。
- 洞府頁：背包 / 煉丹 / 裝備 / 功法四頁籤，內容使用完整寬度。
- 背包每頁 4 格，保持大字與可讀性。
- 角色頁：2 × 4 屬性格＋改名。
- 全局字級重新統一，不再各區忽大忽小。
- 保留既有 IndexedDB 存檔與遊戲功能。
- GitHub Pages 測試網址：?v=17
