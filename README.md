# 無盡仙途 V0.7 — 手機介面重構版

這版依照實機參考方向，把介面由「長網頁」改成「固定手機遊戲框架」。

主要變更：
- 整個遊戲固定在一個手機視窗高度，不再讓整個網頁無限往下延伸。
- 底部導航固定，不需要滑到底才能換頁。
- 頂部新增固定精簡狀態列：境界 / 修為 / 靈石 / 戰力。
- 各功能頁自己在內容區捲動。
- 歷練仍為左右雙欄，戰鬥紀錄固定在歷練頁頂部。
- 背包、煉丹、裝備、功法維持雙欄緊湊格狀。
- 裝備欄固定在裝備區上方，方便查看。
- 桌面瀏覽器會限制為接近手機直式寬度，方便之後轉 iOS。
- 沿用既有 IndexedDB 存檔。

啟動：START_GAME.bat

若仍顯示舊版：
F12 → Application → Service Workers → Unregister → Ctrl + F5

不要清 IndexedDB。
