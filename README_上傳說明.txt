無盡仙途 V19 — iPhone 好上傳版

手機只需要覆蓋 2 個檔案：
1. index.html
2. service-worker.js

特色：
- 單一 index.html 內嵌 CSS + JS，不再需要上傳 css/、js/ 資料夾。
- 沿用 IndexedDB：wujin-xiantu-db / save / main-save，會盡量沿用舊存檔。
- 米白＋墨綠＋金色數值 UI。
- 背包改成上下滑動。
- 裝備可翻頁、點選、比較、換上。
- 歷練有攻防往返動畫，不直接跳結果。
- 體力無限且不顯示。
- 角色名稱可修改，輸入中不會被每秒 render 蓋回原名。
- GitHub Pages 測試：?v=19
